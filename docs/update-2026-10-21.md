# 修复测试数据上传与气球颜色设置

这次替换前后端镜像即可。数据库不需要执行 SQL，原 `.env`、服务密码、评测机镜像和数据挂载继续使用。

- 测试数据 ZIP 上传改为经过统一 Axios 请求，发送当前登录凭证，并处理登录凭证刷新、上传进度及取消。后台题目编辑页和团队题目编辑页均已修复；上传接口仍要求登录和管理权限。
- 气球颜色请求补充比赛 ID。后端也兼容旧页面只发送记录 ID、颜色的请求：根据数据库里的真实比赛题目记录检查权限，不再把缺少比赛 ID 误判成无权管理。伪造比赛或题目归属、其他管理员越权操作仍会被拒绝。
- 修改颜色时保留比赛、题目关联和原题号、标题，避免把部分更新请求里缺少的字段用于同步记录。

把原 Compose 的前后端镜像替换为：

```yaml
# hoj-backend
image: yunyunjuan/sxuoj-backend:contest-security-20261021
# hoj-frontend
image: yunyunjuan/sxuoj-frontend:contest-security-20261021
```

在原 Compose 目录执行，原有额外参数继续带上：

```bash
docker compose pull hoj-backend hoj-frontend
docker compose up -d --no-deps --force-recreate hoj-backend hoj-frontend
```

刷新管理员页面再上传或设置气球颜色。页面仍使用旧资源时按 `Ctrl+F5`；登录本身已过期时重新登录即可。

本次不修改线上数据，不自动调整比赛所有者或管理员权限。保留此前的保密赛、手动解封、评测响应和图表修复。
