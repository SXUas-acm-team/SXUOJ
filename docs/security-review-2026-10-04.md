## 已修复的业务与异步问题

- **题目导出附件混淆**：判题附件误写入 `userExtraFile`，覆盖用户附件，重新导入后可能把判题文件变成用户文件。现在两个字段独立导出，并验证只有判题附件时也不会生成用户附件。
- **远端旧结果误关联**：新提交清除旧远端 ID；POJ/HDU/AtCoder 提交前读取 ID 基线，只接受更大的提交 ID。查询列表失败会中止提交，不能继续采用账号旧 AC。
- **远程轮询异常与资源遗留**：空响应、非法状态和持久化异常在有限重试内处理；保存失败时缓存本次响应，防止 CF 测试点游标前进后丢数据。提交落库失败、调度失败、超时和正常完成均尝试释放带版本的账号租约，旧任务不能删除新任务。
- **正确判定被同步错误覆盖**：终态保存成功后仅重试派生表同步；同步持续失败时保留 AC/WA，记录错误并释放资源，不改成提交失败。此时相关统计表可能仍需恢复数据库后重新同步，日志保留诊断信息。
- **远端题号截断**：AtCoder 来源字符串只分割第一个连字符，CF/GYM 支持完整多字母索引；远程提交等待尊重中断。
- **比赛页旧响应回写**：前端按比赛、请求类型、清理版本和登录会话识别响应；旧页面或旧账号的详情、题目及权限响应不能修改当前共享状态。不同请求类型仍可合法并行。权限 API 失败能正常 reject，不再永久 pending。
- **排名页与定时器**：比赛排名和公开榜单旧响应不会覆盖新页或结束新请求的 loading；重复开启刷新清理旧定时器，页面销毁后晚响应不能重启定时器。比赛注册避免重复发送，旧登录会话不能授予当前会话 access。后端鉴权仍是实际安全边界。
- **额外文件编辑**：管理后台与团队题目共享 JSON/对象配置校验，拒绝数组、非字符串内容和危险属性名；损坏配置保留原值、显式报错并阻止保存。修正判题文件重命名删错键和新增键不触发 Vue 更新。团队题目无样例时也能正常加载。
- **其他边界**：团队 Markdown 图片记录 gid，遗留空 uid 删除流程不会空指针；团队讨论分页受限、删除不存在讨论返回业务错误；训练无分类、空全屏题单正常返回。
