# Markdown 预览固定浅色

这次只需替换前端镜像。后端继续使用 `yunyunjuan/sxuoj-backend:contest-security-20261021`，数据库不用执行 SQL，`.env` 和数据挂载不用改。

题目内容和 Markdown 编辑预览使用固定浅色样式，不再随浏览器深色模式出现黑底。文字、表格和代码块也使用对应的浅色配色。

在原 Compose 文件中修改 `hoj-frontend`：

```yaml
image: yunyunjuan/sxuoj-frontend:contest-security-20261021.1
```

然后在原 Compose 目录执行（原有额外参数继续带上）：

```bash
docker compose pull hoj-frontend
docker compose up -d --no-deps --force-recreate hoj-frontend
```

完成后按 `Ctrl+F5` 刷新页面。需要回滚时，将前端镜像改回 `contest-security-20261021`，再执行上面的两条命令。

GitHub 的 `master` 同时归并了此前分支，详见 [分支合并记录](repository-merge-2026-10-21.md)。分支归并保留当前已发布的后端代码，本次没有新的后端程序改动。
