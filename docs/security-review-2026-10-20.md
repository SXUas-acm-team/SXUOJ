# 本轮安全修复记录

| 已确认问题 | 原影响 | 修复 |
| --- | --- | --- |
| 旧 JWT 只拒绝部分封禁状态 | 登录入口拒绝的非零状态，旧登录会话仍可能通过 | 后端认证只接受正常状态 `0`，封禁时撤销会话 epoch；解除封禁也不能复活已撤销的旧会话 |
| 角色和权限停用未完整生效 | 数据库已停用角色/权限，旧授权仍可能继续使用 | 每个请求核对有效角色和权限，同一请求按用户缓存查询结果；保护附件的 root 特权也核对当前状态 |
| 比赛榜单保留封禁账号 | 原榜单缓存和滚榜仍可能展示被封禁用户，影响名次和奖项 | 内榜、外榜、合并榜、导出和滚榜统一按当前有效账号过滤，再计算名次、奖项和首解；不破坏原始缓存 |
| 删赛缺少密码复核 | 已登录的管理会话可直接触发删除 | 先验证比赛管理权限，再校验操作者自己的账号密码；错误限速，密码只放 JSON 正文，不回显；删除关联记录在同一事务 |
| 独立滚榜没有网站登录鉴权 | 保密赛管理员打开独立页时被当作匿名用户 | 同源 fetch 发送 Authorization，禁止跳转携带凭据，过期或撤权登录只在 401 时安全重试原公开入口 |

测试包含旧 JWT、非零账号状态、角色与权限停用、资源凭证、删赛越权与错误密码、缓存榜单过滤，以及真实 HTTP 的完整保密生命周期。只使用本地隔离库和合成账号，未对线上主机发起扫描或修改。

安装方面另修复旧静态挂载遮盖新前端、旧地址变量不兼容、滚榜资源遗漏，并提供不输出明文凭据的首次安全配置工具；操作步骤见[线上更新手册](upgrade-2026-10-20.md)。
